# Rando Time Planning

Analyze past rides in Ride with GPS to make a time plan for an 
upcoming ride. 

Currently one tool, a web app to extract times of passage
from Ride with GPS records of a route and up to three rides.
Can display time of passing at all cues or just at waypoints and
non-directional cues (e.g., "Control", "Summit").  Time paused is also
displayed for non-directional cues.

The rider's own RWGPS data is accessed using the OAuth protocol, which
allows the rider to log in to RWGPS without revealing password 
information to the web app. 

Future plans:  
   - CLI versions that extract times from GPX files.
   - Export in CSV and XLSX formats
